# Password Generator

A simple password generator application developed using Python as part of my CodSoft Python Programming Internship.

## Features

- User can specify the password length
- Generates random passwords
- Uses letters, numbers, and special characters
- Creates passwords of the specified length
- Handles minimum password length

## Technologies Used

- Python
- VS Code

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `task3.py`.
4. Enter the desired password length.
5. The generated password will be displayed on the screen.
